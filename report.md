# Portfolio Website – Project Report

## Project Overview

A responsive personal portfolio website created to showcase my skills, projects, and contact information in a clean and simple design.

## Technologies Used

* HTML
* CSS
* JavaScript

## Main Features

* Responsive design for desktop and mobile
* Navigation menu
* About Me section
* Skills section
* Projects section
* Contact section
* Mobile hamburger menu

## What I Learned

Through this project, I improved my understanding of responsive web design, JavaScript interactions, page structure, and organizing a frontend project.

## Deployment

The website was deployed online using Vercel.
